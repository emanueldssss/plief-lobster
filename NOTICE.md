This adaptation rewrites the guidance around Plif's existing Sifr ExperienceIR,
DesignDNA, and Orun discovery/selection interfaces. It adds concept-to-code
traceability, actual acquisition/use-site obligations, local retrieval orchestration,
and file-integrity checks for delivery evidence. It does not bundle Impeccable's
CLI, detectors, browser extension, native-platform reference derivatives, or agent
runtime. Their commands and capabilities must not be claimed as installed here.

Upstream-specific approval ceremonies, random selection, provider-specific bans,
and fixed polish ceilings were not carried over. Existing user authorization,
project constraints, and material defect resolution govern this workflow.
